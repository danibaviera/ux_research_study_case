# 8. Síntese

Fluxo: **Transcrição/notas → Codificação → Affinity Mapping → Insights**

- [codificacao.md](codificacao.md): códigos aplicados às falas.
- [affinity-mapping.md](affinity-mapping.md): agrupamento de falas por tema.
- [insights.md](insights.md): insights formulados a partir dos grupos.

Evite insights genéricos ("usuários querem previsões confiáveis"). Um bom insight descreve um comportamento e o porquê, com evidências.
