# Case de UX Research: Radar C

Projeto de pesquisa para investigar como pessoas no Rio de Janeiro buscam, interpretam e usam informações meteorológicas, e transformar os achados em oportunidades de produto para o Radar C (projeto open source de previsão meteorológica). 

Este é uma projeto modelo, que serve de base para pesquisar de UX Research

> Narrativa: **Pesquisa do usuário → comportamento → jornada → necessidade → oportunidade → requisitos → produto → serviço.**

## Como usar este repositório

Cada pasta/arquivo corresponde a uma etapa do case.

**Regra de ouro:** não escreva soluções antes de ter evidências. Hipóteses e perfis são *hipóteses* até a pesquisa dizer o contrário.
