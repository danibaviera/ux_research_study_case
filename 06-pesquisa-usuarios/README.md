# 6. Pesquisa com usuários

## Amostra

Meta: **8–12 entrevistas individuais**, variando entre os grupos abaixo. Não criar personas antes: primeiro descobrir os padrões.

| Grupo | Perfil | Meta | Realizadas |
|-------|--------|:----:|:----------:|
| A - População geral | Consulta previsão para roupa, deslocamento, compromissos | 3–4 | 0 |
| B - Deslocamento | Transporte público, moto, bicicleta ou muito tempo na rua | 3–4 | 0 |
| C - Sensíveis ao clima | Entregadores, trabalhadores externos, esportistas, responsáveis por crianças | 2–4 | 0 |
